# semicircle-decay-sim

リアクションホイールを搭載した左右ロッキング機体について、実機の自由減衰と足裏形状を物理モデルで比較するためのリポジトリです。

## 目的

現在ファームウェアで使っているピーク間自由減衰モデルと、実際の足裏接触形状に基づく簡略物理モデルを比較します。

特に以下を切り分けます。

1. 完全な半円足を仮定したモデルが実機のゼロクロス近傍を正しく表しているか
2. STEP形状にある中央の円弧欠損が、振幅とゼロクロス角速度の関係にどの程度影響するか
3. 薄い造形足の弾性変形が中央接触・荷重分担・減衰へ与える影響
4. 自由減衰で得たモデルをリアクションホイール再構成後へそのまま適用できるか
5. 足裏形状だけで説明できない差を、リアクションホイール状態・左右非対称・接触損失などへ分離できるか

## STEPから確認した座標系

Onshapeから書き出した `Part Studio 1.1.step` を形状参照として解析しています。CADの質量・密度・重心・慣性モーメントは使用しません。

- **X**: 実機の左右方向。正面動画の水平方向
- **Y**: 実機の前後方向。足裏円弧の円筒軸方向
- **Z**: 実機の鉛直方向
- 左右ロッキングは **Y軸回り**

動画の正面像はCADのXZ断面と対応します。

## 足裏形状の重要な発見

STEPの左右足裏外周は、共通の半径150 mmの円筒面です。

- 外側円弧半径: `150.0 mm`
- 内側円弧半径: `148.5 mm`
- 円弧部の半径方向厚さ: **1.5 mm**
- 円弧のY方向幅: **56.0 mm**
- 円筒軸: Y方向
- 円中心線: おおむね `X = 0`, `Z = 56.951 mm`
- 左足の円弧範囲: `X = -45 ... -5 mm`
- 右足の円弧範囲: `X = +5 ... +45 mm`
- 中央の欠損幅: **10 mm**
- 内側端から補強/根元開始付近までの自由弧長: 約 **32.385 mm**

したがって完全円の最下点 `X=0` は実体として存在しません。

内側端点から円弧転がりへ移る剛体幾何学角は

```text
theta_inner = asin(5 / 150) = 1.910 deg
```

外側端点は

```text
theta_outer = asin(45 / 150) = 17.458 deg
```

です。

剛体なら理想化した接触モードは次のようになります。

```text
|theta| = 0
    左右の内側端点が同じ高さ

0 < |theta| < 1.910 deg
    低い側の内側端点を支点にロッキング

1.910 <= |theta| <= 17.458 deg
    R=150 mm の円弧上を転がる
```

実機動画の中央に見える白いテープは、左右揺動試験中に脚が前後へ動かないようにするための拘束で、荷重支持部材としては扱いません。

## Model A / B / C

現在は3段階で比較します。

- **Model A**: 完全円 + 剛体足（従来近似）
- **Model B**: STEPの10 mm中央欠損 + 剛体足
- **Model C**: STEP形状 + 薄い足のコンプライアンス

### Model B: 完全円との差

これまで使ってきた単純な完全円モデルでは、直立時重心高さを `H=120 mm` とすると

```text
Delta h_old = (R - H) * (1 - cos(theta))
```

です。

中央欠損を含む剛体モデルでは、`a=5 mm` として中央端点支点領域で

```text
Delta h_gap = H*(cos(|theta|)-1) + a*sin(|theta|)
```

円弧領域では

```text
hC0 = sqrt(R^2 - a^2)
d = hC0 - H
Delta h_gap = R - d*cos(|theta|) - H
```

とします。

`H=120 mm`, `m=199.7 g` を使うと、6.5--7 deg付近では完全円モデルより必要位置エネルギーが約37--43%大きくなります。

### Model C: 足の変形

STEPで円弧部は **1.5 mm厚**しかありません。中央欠損により失われた完全円の最下点と内側端との高さ差はわずか

```text
0.08336 mm
```

です。

したがって0.1 mm級のたわみでも、中央接触の物理を変える可能性があります。

`model/foot_compliance.py` では材料を固定せず、STEP寸法から梁近似の感度を計算できます。単純梁近似で `E=1..3 GPa` を振ると、半荷重時の変位は概略 `0.24..0.70 mm` です。ただし、これは曲率・積層方向・根元形状を簡略化したスクリーニング値であり、実機剛性として採用してはいけません。

半荷重時のたわみが0.08336 mmと等しくなる有効剛性は約

```text
11.75 kN/m per foot
```

なので、実測剛性がこれより低ければ、中央欠損より足変形の方が変位量として大きくなります。

また中央を2本のばね支持として近似すると、剛性によっては両足同時接地が剛体の1.910 deg境界付近まで残り得ます。このため最終モデルでは「片側の一点接触だけ」を前提にしない必要があります。

詳細は `docs/2026-08-24_flexible_foot_analysis.md` を参照してください。

## 現時点の実測との比較

2026-08-24 V61 run 2の自由減衰区間について、動画ピーク角とIMUジャイロのゼロクロス角速度を使い、各側ごとに一定の有効慣性 `J` を1個だけフィットしました。

ゼロクロス角速度のRMSEは概略:

| 前のピーク側 | Model A: 完全円 | Model B: 中央欠損剛体 |
|---|---:|---:|
| 負側ピーク -> 正方向ゼロクロス | 8.67 deg/s | **3.28 deg/s** |
| 正側ピーク -> 負方向ゼロクロス | 4.31 deg/s | **1.60 deg/s** |

この比較では中央欠損を入れるだけでRMSEが約62--63%低下しました。

一方、V61の再構成区間では、Model Bでも自由減衰から予測した速度に対して方向依存のずれが残ります。したがって中央欠損は重要ですが、V61再構成後の不一致をこれだけで全て説明することはできません。

Model Cについては足剛性の実測後に同じデータへ適用します。足の単純曲げ応答はボディの揺動より十分速い可能性が高いため、現段階では「半周期ずっと残る弾性状態」より、**接触切替・荷重分担・ヒステリシス・左右剛性差**を主な影響として検証します。

## 実行例

```bash
python analysis/compare_contact_geometry.py
python analysis/estimate_foot_flexibility.py
python analysis/compare_model_abc.py
python -m unittest discover -s tests -v
```

`compare_model_abc.py` はModel Cの剛性を感度値として指定できます。

```bash
python analysis/compare_model_abc.py --stiffness 5000 7500 10000 15000
```

## 参照方針

- `study_AT`: **参照専用**。このリポジトリからは書き換えない
- CAD/STEP: 形状・寸法だけに使用する
- 質量、重心、慣性: 実測値または実測ログから同定する
- 足剛性・減衰: 実測または実測ログから同定する。CAD材料値から決めない
